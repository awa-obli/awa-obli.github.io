开始编程前的准备

发表于 2025-08-17 更新于 2026-06-26 分类于 计算机社 阅读次数：
在写下第一行Python代码之前，你还需要做的事——安装Python解释器和代码编辑器。🔧

以下安装教程仅适用于Windows，请确保你的电脑版本在Win10及以上，信息有效性截止于2025/4/19，请注意甄别。

📌在写下第一行Python代码之前，你还有两件事情需要做：

  • 安装Python解释器

  • 安装代码编辑器

一. 安装Python解释器

1. 为什么？

机器其实是没有办法直接读懂我们写的Python代码的，
而是需要一个解释器，作为中间的翻译，把源代码转换成字节码[1]（编译）后再逐条解释并执行。

我们一般说安装Python，本质上指的就是安装Python解释器

2. 安装教程：

  1. 进入Python官网：https://www.python.org
  2. 点击“Downloads”

  1. 点击“Download Python 3.X.X”

  1. 等待下载完成ing…（如果遇到网络问题无法下载或下载缓慢，可以访问：https://wwuu.lanzouo.com/b00zxp3i2d；密码：“python123”）
  2. 运行安装包
  3. 勾选两个选项（前者：使系统的所有用户都可以使用Python Launcher[2] -> py.exe；后者：将Python添加至PATH环境变量[3]，以便在在终端运行Python）

  1. 最后点击“Install Now”（即默认安装）
  2. 等待安装完成ing…
  3. *测试是否安装成功：
    1. 在“搜索栏”搜索“cmd”并进入（或win+r快捷键打开运行窗口，进入“cmd”）
    2. 键入python，如果显示内容与下图相近，则安装成功，yeahhh~🎉

二. 安装代码编辑器

1. 为什么？

就好比我们写文档大多用Word，
写代码也需要一个专门的软件来帮助提高编码效率、减少出错，
而代码编辑器就是程序员写代码的专用工具。

如图（VS Code）：

2. 介绍：

现在已经有非常多的代码编辑器：Vim、Emacs、Visual Studio Code、Atom、Sublime Text、Pycharm…

如图（顺序同上）：

接下来为大家隆重介绍两款：

(1) PyCharm

  • 它是由JetBrains公司专门为Python设计的编辑器

​ Pycharm不止可以用来写代码，它的本质叫做IDE[4]，除了拥有代码编辑器的代码高亮、自动补全、自动格式化、拼写检查等智能功能之外，还包含有调试器、版本控制工具、项目管理工具等，肥肠的强大。

(2) Visual Studio Code（VS Code）

  • 它是由Microsoft公司开发的开源免费、轻量级的代码编辑器

​ VS Code集成了代码高亮、智能补全、调试、版本控制等功能，并拥有丰富的扩展市场，可通过插件支持多种编程语言和开发工具。其简洁的界面、强大的性能和高度可定制性，使其成为开发者广泛使用的工具之一。

↓下面是两款编辑器的安装教程↓

3. 安装教程：

  • PyCharm
  • VS Code

(1) 安装PyCharm

  1. 进入PyCharm官网：https://www.jetbrains.com/zh-cn/pycharm/
  2. 点击“下载”

  1. 下滑，找到“社区版”，点击“下载”（社区版免费）

  1. 等待下载完成ing…
  2. 运行安装包
  3. 点击”下一步“

  1. 选择”安装目录“后，点击”下一步“

  1. 选择”安装选项“后，点击”下一步“（按需选择即可，这里我选择了前三项）

  1. 选择”开始菜单文件夹”后，点击“安装”

  1. 等待安装完成ing…

  2. *测试是否安装成功：
    在桌面成功打开则安装成功，yeahhh~🎉

(2) 安装VS Code

  1. 进入VS Code官网：https://code.visualstudio.com/
  2. 点击右上角“Download”

  1. 选择“System Installer”进行下载（如果直接点击首页“Download for Windows”进行下载，下载到的安装包为此处的“User Installer”，则只会为当前用户安装，而选择“System Installer”则会为所有用户安装，因此推荐后者）

  1. 等待下载完成ing…
  2. 运行安装包
  3. 点击“同意“后，再点击”下一步“

  1. 选择”安装目录“后，点击”下一步“

  1. 选择”开始菜单文件夹”后，点击“下一步”

  1. 选择”附加任务“后，点击”下一步“（按需选择即可，这里我选择了前三项和最后一项）

  1. 最后点击”安装“

  1. 等待安装完成ing…
  2. *测试是否安装成功：
    在桌面成功打开则安装成功，yeahhh~🎉

  1. 字节码（bytecode），一种介于源代码和机器码之间的中间表示形式。 ↩︎

  2. Python Launcher（Python 启动器），它是 Python 官方提供的一个工具，主要用于在 Windows 系统上更灵活地管理和运行不同版本的 Python。 ↩︎

  3. 环境变量（environment variables），是在操作系统中一个具有特定名字的对象，它包含了一个或者多个应用程序所将使用到的信息。其中PATH是一个特殊的环境变量，它告诉系统，当要求系统运行一个程序而没有告诉它程序所在的完整路径时，系统除了在当前目录下面寻找此程序外，还应到哪些目录下去寻找。 ↩︎

  4. IDE（Integrated Development Environment “集成开发环境”），它将开发过程中常用的功能集成在一个统一的界面中，通过提供一个集中的工作环境，IDE简化了编写、测试和调试代码的流程，减少了在不同工具之间切换的时间。 ↩︎
